# Obsidian のノートの編集

Obsidian の vault にある markdown を作成, 更新するときに適用する規則である.
vault の外の文書や会話には適用しない.

## 編集前に読むもの

1. 対象のフォルダにあるページと, 同じ主題の関連ページを先に読む.
2. 索引ページがあれば読み, 新しいページをどこに置くかを決める.
3. 利用者が手で修正した図や文は, 編集の直前に最新の内容を読み直す.
   利用者の修正は保ったまま, 必要な箇所だけを変更する.

## 既存のページとの関係

1. 重複するページを増やさず, 既存のページに統合し, リンクでつなぐ.
2. データ構造の説明と, その構造を使う機能の説明は, 相互にリンクする.
3. 複数のトピックに共通する入口(システムコールの受付など)は, 専用ページにまとめる.
   各ページは, 共通入口へのリンクと, 固有の処理を持つ.

## リンクの書き方

1. 見出しへのリンクは `[[ページ名#見出し|表示名]]` と書く.
2. 表の中の別名付きリンクは, `|` を `\|` にして区切りと区別する.

```markdown
| ページ | 内容 |
|--------|------|
| [[メモリ管理/pageとfolio\|page と folio]] | ページの管理情報 |
```

3. ページを移動したときと, 見出しを変えたときは, 旧名で検索して参照元のリンクを更新する.
4. 新しいページは, 索引ページに1行の説明つきで追加する.
   移動したページは, 索引の位置も更新する.

## frontmatter

| キー | 内容 |
|------|------|
| `tags` | 分類の語 |
| `source_version` | 対象の版 (`linux-7.2.8` など) |
| `source_tree` | ローカルのソースツリーの場所. 本文には書かない |
| `status` | 草稿は `draft` |
